# Gamma Solo

A local-first, offline-capable solo science-fantasy campaign console. All included names, generators, creatures, artifacts, and tables are original placeholders; no published rules text or protected game data is included.

## Run locally

1. Open a terminal in this folder.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address shown by Vite.

Use `npm run build` for a production build.

## Included

- Seeded character and 6–30-area ruin generators
- Text node maps, exploration areas, and four manual ruin clocks
- D100 solo oracle and fast event prompts
- Encounter, hazard, artifact, salvage, settlement, and faction tools
- Persistent global dice roller with custom expressions
- Campaign journal with links, tags, search, and quick logging
- LocalStorage persistence and JSON campaign import/export
- Editable custom tables and full reset controls
- Print layouts for field reports and character sheets
- Responsive desktop/tablet/mobile interface

Campaign data remains in the browser on the local device unless explicitly exported.
